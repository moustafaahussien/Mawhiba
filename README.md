# منصة الموهبة – مدارس دار الذكر

الإصدار الأول: الصفحة الرئيسية + صفحة المؤشرات والتقارير.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية (رحلة الموهبة، الأرقام، أقسام المنصة، رابط المنصة الشقيقة) |
| `kpis.html` | المؤشرات والتقارير (ملخص تنفيذي، 11 مؤشراً، مقارنة الأعوام، مسار المسابقات، التقارير، طباعة PDF) |
| `tools/talent-data-script.gs` | سكربت Google Apps Script يقرأ جدول البيانات ويغذي الصفحتين |
| `assets/school-logo.png` | (اختياري) شعار المدرسة — يظهر في الرئيسية تلقائياً إن وُجد |

## ربط البيانات (مرة واحدة)
1. أنشئ Google Sheet فارغاً باسم «بيانات منصة الموهبة».
2. Extensions ← Apps Script، والصق محتوى `tools/talent-data-script.gs` واحفظ.
3. شغّل الدالة `setupSheet` ← تُنشأ أربعة تبويبات جاهزة: **الأرقام، المؤشرات، مسار المسابقات، التقارير**.
4. Deploy ← New deployment ← Web app (Execute as: Me، Who has access: Anyone)، وانسخ رابط `/exec`.
5. ضع الرابط في السطر `const DATA_SCRIPT_URL = '';` في `index.html` و`kpis.html`.

## التحديث اليومي
اكتب الأرقام في الجدول فقط — يظهر كل شيء في الموقع عند فتحه.
- **المؤشرات**: لإضافة عام دراسي جديد أضف عموداً بعد آخر عام (مثل `2027-2028`).
- **التقارير**: ارفع التقرير PDF على Drive، واجعله «أي شخص لديه الرابط»، وضع رابطه في عمود «الرابط».
- الخانات الفارغة تظهر «—» و«بانتظار البيانات»؛ لا يعرض الموقع أي رقم غير حقيقي.

> ⚠️ الموقع عام: لا تكتب في الجدول أسماء طلاب أو نتائج فردية — الأرقام الإجمالية فقط.
